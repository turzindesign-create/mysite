Guia do site turzin.

Mapa dos arquivos do site (index.html, as páginas de projeto e case.css): onde mudar cores, fontes, logo, textos, imagens e o tempo das animações. Os números de linha valem para o arquivo como ele saiu daqui.

Como editar sem medo
  1. Faça uma cópia da pasta antes de mexer.
  2. Abra a pasta do site no VS Code (grátis). Ele mostra o número de cada linha. Atalho para ir direto a uma linha: Ctrl + G e digite o número.
  3. Mude só o valor (a cor, o número, o texto). Não apague aspas, ponto e vírgula, vírgulas nem os sinais < >.
  4. Salve e abra o index.html no navegador para ver. Gostou? Arraste a pasta no Netlify.
  5. Os números de linha mudam se você acrescentar ou apagar linhas. Se não achar, use Ctrl + F e procure pelo texto, ou pelas etiquetas [GUIA: ...] que deixei no código.
Os dois “painéis de controle”
Quase tudo fica em dois lugares: o painel CSS no começo do arquivo (linha 35: cores, fontes, tamanhos e tempos) e o painel JavaScript perto do fim (linha 687: contato, velocidades e imagens dos projetos).
